# NyayaSetu — India's Citizen Action Guide ⚖️🇮🇳

**NyayaSetu** is an independent citizen-guidance platform built by **Team Sankalp** for the Tech Tomorrow Project. It empowers citizens across India by simplifying complex public service procedures, providing deterministic issue routing, required document checklists, ready-to-use request drafts, and direct links to official government portals.

---

## 🌟 Key Features

- **8 Curated Public Action Categories**:
  1. Consumer Grievances & Refunds (NCH 2.0)
  2. Public Infrastructure & Road Repair (CPGRAMS / Local Municipalities)
  3. Electricity & Utility Issues (DISCOM / State Electricity Ombudsman)
  4. Municipal Water Supply Problems (Jal Board / Municipal Helplines)
  5. Scheme & Benefit Discovery (myScheme / Direct Benefit Transfer)
  6. Digital Payment & Banking Issues (RBI Ombudsman / UPI CMS)
  7. Public Health & Hospital Guidance (Ayushman Bharat PM-JAY)
  8. Student & Education Guidance (National Scholarship Portal / UGC e-Samadhan)
- **100% Offline Local Privacy**: No PII, Aadhaar numbers, or sensitive credentials collected. Action plans and drafts remain strictly in your browser's `LocalStorage`.
- **Deterministic Routing**: Question-based wizard maps citizen issues directly to the appropriate official authority.
- **Zero Government Impersonation**: Clear disclaimers and explicit outbound links to official domains (`pgportal.gov.in`, `myscheme.gov.in`, `consumerhelpline.gov.in`, `cms.rbi.org.in`, `scholarships.gov.in`).

## 🚀 Live Demo & Deployment on GitHub Pages

NyayaSetu is optimized for static hosting on **GitHub Pages**.

### How to Deploy:
1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository settings:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Choose branch `main` and folder `/ (root)`.
   - Click **Save**.
3. Your site will be live at:
   `https://<your-username>.github.io/<repo-name>/`
